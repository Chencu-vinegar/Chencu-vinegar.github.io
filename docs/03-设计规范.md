# 03 设计规范（Design System）

> 定义个人主页的**视觉风格、色彩、字体、布局、间距、动效与响应式原则**。
> 本文件描述**已落地**的规范（与 `styles/main.css` 中的 Token 一一对应），修改样式时请同步更新此处。

## 1. 设计风格方向

| 风格 | 关键词 | 适用人群 |
| --- | --- | --- |
| A. 极简专业 | 留白、克制、无衬线、灰白黑 + 单一强调色 | 求职 / 设计 / 技术 / 商务 |
| B. 创意活泼 | 圆角、饱和撞色、插画、模糊玻璃 | 创意 / 设计师 / 内容创作者 |
| C. 科技未来 | 深色、发光渐变、等宽字体点缀、网格 | 开发者 / AI / 极客 |
| D. 温暖亲和 | 暖色调、圆润、手写点缀 | 生活 / 个人品牌 / 教育 |
| **E. 高对比色块版式（当前）** | **大色块、超大字号、粗字重、硬边描边、胶囊标签、低对比副文字** | 个人品牌 / 视觉冲击力优先 |

- 历史：初版为 **A（极简专业）**。
- **当前：E（高对比色块版式）**，2026-09-17 确认改造方向为「整页重排版式、保留蓝青主色」。

### 1.1 版式语言的四条规则
1. **色块先行**：首屏由「左侧饱和蓝大色块 + 右侧浅底速览卡片」拼成，不做居中式 Hero。
2. **字号落差大**：标题 900 字重 + 负字距（`-0.02em ~ -0.04em`），正文回到 400 字重，中间层级少而清晰。
3. **硬边描边**：大面板/卡片/按钮一律 `border-radius: 0`，用 2px 描边与实色横线划分区域，不用阴影堆叠。
4. **低对比副文字**：色块内的英文大写关键词、页脚超大姓名，用低透明度（0.10–0.16）作为版式装饰，不承载信息。

### 1.2 改造边界（版权与合规）
只借鉴**不受版权保护的版式语言**（配色逻辑、分栏结构、字号层级、组件形态）。以下内容**不引入**：
- 第三方品牌名、Logo、图标、插画、照片素材（头像除外，为用户本人照片）；
- 第三方商业字体文件（仅使用系统字体栈，`head` 中不含任何外部字体/CDN 请求）；
- 参考站点的原文案（站内所有文案均为自写）。

## 2. 色彩

### 2.1 色彩 Tokens（与 CSS `:root` / `[data-theme="dark"]` 一致）

| Token | 用途 | 浅色 | 深色 |
| --- | --- | --- | --- |
| `--color-bg` | 页面背景 | `#ffffff` | `#070a10` |
| `--color-surface` | 卡片/交替区块背景 | `#f4f6fa` | `#0f151f` |
| `--color-text` | 正文文字 | `#0c1420` | `#e9eef6` |
| `--color-muted` | 次要文字 | `#5a6779` | `#93a1b3` |
| `--color-border` | 边框 / 分隔线 | `#dfe4ec` | `#1e2733` |
| `--color-accent` | 强调色（蓝，**保留原主色**） | `#2f6fed` | `#5b8def` |
| `--color-pop` | 辅色（青，点缀用） | `#0fb5a5` | `#2ee6c8` |
| `--color-block` | 首屏大色块底色 | `#1746c9` | `#12307a` |
| `--color-block-ink` | 大色块上的文字色 | `#ffffff` | `#ffffff` |
| `--color-line` | 硬横线（区块标题下划线、页脚上边线） | `#0c1420` | `#e9eef6` |

**主色策略**：蓝青双色不变，仅**调整容器形态**（由「浅灰卡片 + 柔和阴影」改为「饱和蓝大色块 + 青字点缀」）。

### 2.2 状态色
| 状态 | 色值 | 用途 |
| --- | --- | --- |
| 成功 | `#16a34a` | 反馈提交成功 |
| 错误 | `#dc2626` | 校验失败 / 提交失败 |
| 进行中 | `var(--color-accent)` | 提交中提示 |
| 在线 | `#22c55e` | 数字分身在线上状态点 |

### 2.3 对比度要求
- 正文与背景对比度 ≥ 4.5:1（WCAG AA）；大标题可放宽到 3:1。
- 色块上的副文字使用 `rgba(255,255,255,.82)`，不低于 .78。

## 3. 字体

- **主字体**：`Inter` → `PingFang SC` → `Microsoft YaHei` → `system-ui` → `-apple-system` → `Segoe UI` → `Roboto`（`--font-sans`）。
- 标题：同族，靠**字号 + 900 字重 + 负字距**拉开层级，不换字体。
- **不加载任何外部字体文件**（版权 + 隐私 + 首屏性能）。
- 装饰性英文大写（如 `CODE · BUILD · EXPLORE`、`TJU × HKPU`）：`font-weight: 800–900` + `letter-spacing: 0.06–0.24em`、`text-transform: uppercase`。

## 4. 排版与间距

### 4.1 字号阶梯（已落地）
| 层级 | Token / 取值 | 字重 | 用途 |
| --- | --- | --- | --- |
| Hero 标题 | `--fs-hero`: `clamp(38px, 5.6vw, 74px)` | 900 | 首屏姓名 |
| 区块标题 | `--fs-h2`: `clamp(28px, 3.4vw, 44px)` | 900 | 关于 / 经历 / … |
| 导语 Lede | `clamp(18px, 2vw, 25px)` | 700 | 关于我首句 |
| 卡片/时间线标题 | `clamp(17px, 1.6vw, 20px)` | 800 | H3 |
| 正文 | 继承（约 16px） | 400 | 段落 |
| 小标签 | 12–13.5px | 600–800 | 胶囊标签 / 序号 / 表单项 |

### 4.2 间距
- 区块上下间距：`clamp(56px, 7vw, 100px)`
- 色块内边距：`clamp(32px, 4vw, 64px)`
- 卡片内边距：`24–26px`；栅格间隙：`16–48px`

### 4.3 布局约束
- 内容最大宽度：`--max-width: 1200px`（居中，左右 `24px` 安全边距）
- **圆角：`--radius: 0`**（大面板、卡片、输入框、按钮全部直角；仅胶囊标签/头像用 `999px` / `50%`）
- 吸顶导航高度：`--header-h: 68px`；`html { scroll-padding-top: calc(var(--header-h) + 16px) }` 避免锚点被导航遮挡
- 分层原则：优先「2px 描边 + 实色横线」划分，不使用 `box-shadow` 堆叠

### 4.4 组件形态
| 组件 | 规范 |
| --- | --- |
| 主按钮 | 实色 `--color-accent` 底 + 白字，hover 反转为文字色底 |
| 次按钮 | 透明底 + 2px 描边，hover 描边转强调色 |
| 色块内按钮 | 白底反色（primary）/ 白色半透明描边（ghost） |
| 胶囊标签 | `border-radius: 999px`、1px 描边、12.5px / 600 |
| 区块标题栏 | 标题（900）+ 右侧两位序号（`letter-spacing: .22em`），下方 2px 实色横线 |
| 首屏速览卡 | 头像 + 「技能关键词」标签云 + 三段事实列表（`dl`） |
| 下滚箭头 | 18×18 的 `border-right/bottom` 直角，`rotate(45deg)` + 上下浮动动画 |

## 5. 图形与图标
- **不引入第三方图标库**（避免额外的资源与授权问题）。
- 现有图形元素全部自制：`◐`（主题切换）、`×3` 汉堡线条、CSS 绘制的 V 形下滚箭头、`●` 状态点。
- 头像：`assets/images/avatar.jpg`，缺失时回退为「陈」字（首屏）与「渠」字（数字分身）。

## 6. 动效原则
- 时长：`150–250ms`；缓动：`ease` / `ease-in-out`。
- 作用范围：按钮描边与配色切换、导航项下划线、卡片描边、主题切换的 250ms 配色过渡、下滚箭头循环浮动、数字分身头像呼吸光圈、输入中三点动画。
- 克制原则：不做位移/缩放式「上浮」卡片；动效服务于状态反馈。

## 7. 响应式断点（已落地）
| 断点 | 宽度 | 布局变化 |
| --- | --- | --- |
| 桌面 | ≥ 941px | 首屏左右分栏；关于我 2 栏；时间线「年份 + 内容」2 栏；联系卡片 2 列 |
| 平板 | 801–940px | 首屏改上下堆叠；关于我单栏；数字分身上下堆叠（面板横向） |
| 手机 | ≤ 800px | 汉堡菜单展开；时间线单栏；联系卡片单列 |
| 小屏 | ≤ 560px | 表单双列改单列；反馈按钮全宽；色块内边距收紧 |

## 8. 可访问性与规范
- 所有图片加 `alt` 文本；纯装饰文字用 `aria-hidden="true"`。
- 交互元素可键盘访问，且必须有可见焦点态（`outline: 2px solid var(--color-accent); outline-offset: 2px`）。
- 文字尽量不使用纯亮色（黄/绿）作为唯一信息传达手段。
- 表单的选填/必填、字数上限、提交状态均需可见（`role="status"` + `aria-live="polite"`）。
