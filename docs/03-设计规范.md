# 03 设计规范（Design System）

> 定义个人主页的**视觉风格、色彩、字体、布局、间距、图标、动效与响应式原则**。所有数值均为「建议默认值」，可按你的偏好调整（已标注「建议默认」）。

## 1. 设计风格方向（待确认）

| 风格 | 关键词 | 适用人群 |
| --- | --- | --- |
| A. 极简专业 | 留白、克制、无衬线、灰白黑 + 单一强调色 | 求职 / 设计 / 技术 / 商务 |
| B. 创意活泼 | 圆角、饱和撞色、插画、模糊玻璃 | 创意 / 设计师 / 内容创作者 |
| C. 科技未来 | 深色、发光渐变、等宽字体点缀、网格 | 开发者 / AI / 极客 |
| D. 温暖亲和 | 暖色调、圆润、手写点缀 | 生活 / 个人品牌 / 教育 |

**默认建议：A（极简专业）。你的偏好（已确认）：A（极简专业）**

## 2. 色彩

### 2.1 色彩 Tokens（建议默认——极简风格）

| Token | 用途 | 建议值 |
| --- | --- | --- |
| `--color-bg` | 页面背景 | `#ffffff`（浅色） / `#0f1115`（深色） |
| `--color-surface` | 卡片背景 | 浅色 `#f7f8fa` / 深色 `#1a1d23` |
| `--color-text` | 正文文字 | 浅色 `#1f2933` / 深色 `#e5e7eb` |
| `--color-muted` | 次要文字 | `#6b7280` |
| `--color-accent` | 强调色 / 链接 / 按钮 | 建议 `#2f6fed`（可换） |
| `--color-border` | 边框 / 分隔线 | `#e5e7eb` / `#2a2f38` |

- **强调色**一旦选定，全站统一使用，用于按钮、链接、高亮、悬停态。

### 2.2 对比度要求
- 正文与背景对比度 ≥ 4.5:1（WCAG AA）；大标题可放宽到 3:1。

## 3. 字体

- **主字体**：建议 `Inter`、`PingFang SC`（中文）、`Microsoft YaHei`、系统 sans-serif 回退。
- **标题**：可与正文同族、加大字号 + 字重（600/700）。
- **点缀字体（可选）**：代码/数字可用 `JetBrains Mono`。

## 4. 排版与间距

### 4.1 字号阶梯（建议默认）
| 层级 | 字号 | 字重 | 用途 |
| --- | --- | --- | --- |
| H1 | 40–56px | 700 | Hero 大标题 |
| H2 | 28–36px | 700 | 区块标题 |
| H3 | 20–24px | 600 | 卡片标题 |
| Body | 16px | 400 | 正文 |
| Muted | 14px | 400 | 次要信息 |

### 4.2 间距（单位 8px 网格）
- 区块上下间距：`80–120px`
- 卡片间距：`24–32px`
- 内边距（卡片）：`24px`

### 4.3 布局约束
- 内容最大宽度：`1100–1200px`（居中）
- 卡片圆角：`8–16px`（极简建议 `12px`）

## 5. 图标
- 统一线性 / 单体图标库，建议使用同一套（如 `lucide-icons`、`heroicons`）保持风格一致。
- 社媒图标单独替换为品牌图标。

## 6. 动效原则
- 时长：`150–300ms`；缓动：`ease-out`。
- 作用范围：卡片 hover 上浮 / 描边、链接下划线、按钮状态、锚点平滑滚动。
- 克制原则：不花哨，不加戏，动效服务于理解与反馈。

## 7. 响应式断点（建议默认）
| 断点 | 宽度 | 布局 |
| --- | --- | --- |
| 桌面 `lg` | ≥ 1024px | 导航横向，作品 3 列 |
| 平板 `md` | 768–1023px | 作品 2 列 |
| 手机 `sm` | < 768px | 单列，汉堡菜单 |

## 8. 可访问性与规范
- 所有图片加 `alt` 文本。
- 交互元素可键盘访问，且必须有可见焦点态。
- 文字尽量不使用纯亮色（黄/绿）作为唯一信息传达手段。
