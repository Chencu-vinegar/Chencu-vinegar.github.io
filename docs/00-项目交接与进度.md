## 5. 源文件关键信息（新对话注意）

- **入口**：`index.html`（单页，所有区块集中在此文件）。

- **首屏结构**：`.hero-grid` 左右分栏 —— 左 `.hero-block`（饱和蓝大色块：eyebrow / 超大姓名 / 定位句 / `.chip` 胶囊标签 / CTA / `.hero-keywords` 低对比大字），右 `.hero-side`（头像 + 「技能关键词」`.skill-cloud` + `.side-facts` 事实列表）；下方 `.scroll-cue` 为 CSS 绘制的 V 形下滚箭头。桌面 1.5:1，≤940px 上下堆叠。
- **区块标题组件**：`.section-head`（`.section-title` + `.section-index` 两位序号 + 2px 实色下划线），序号 01–05 与五个内容区块一一对应。
- **交互**：`scripts/main.js` —— 纯原生 JS（**ES5 语法**，不用 `let`/`const`/箭头函数/模板字符串），无依赖。两个表单（`.feedback-form` 与 `.contact-form`）共用同一提交流程（`submitFeedback()` 判断直连 Supabase 还是走后端）。
- **数字分身调用链（三层降级，改这里最容易踩坑）**：
  - `chatTargets()` 按环境给出候选地址：本地（`file:` / `localhost` / `127.0.0.1`）优先同源 `/api/chat`，线上优先 `SITE_CONFIG.chatUrl`（Edge Function），另一条排在后面兜底。
  - `postChat()` 依次尝试，失败换下一个；`chatHeaders()` 给 Edge Function 带上 `apikey` / `Authorization`（publishable 公钥）。
  - 全部失败 → `localReply()` 本地关键词回复，页面绝不报错。
  - `refreshAvatarStatus()` 在页面加载后探测后端，把 `#avatarStatus` 置为「● AI 在线」或「● 演示模式」；`askAvatar()` 是发送入口（旧的 `askBackend()` 已更名）。
- **前端公开配置**：`scripts/config.js` 定义 `window.SITE_CONFIG`（`supabaseUrl` / `supabaseKey` / `supabaseTable` / `chatUrl`），在 `index.html` 中**先于 `main.js`** 加载。填了地址与密钥 → 反馈浏览器直连 Supabase；留空 → 回退同源 `/api/feedback`。`chatUrl` 留空则跳过 Edge Function。用 publishable 公钥是 Supabase 的既定用法，**切勿**把 `service_role` 密钥写进此文件。

- **本地服务启动（Windows 注意）**：`Start-Process py server.py` 在本环境会留下多级僵尸进程（`py.exe` → `python3.exe` → `python.exe` 抢同一端口，`SO_REUSEADDR` 使旧进程继续截获请求），且子进程会随调用方 shell 结束被回收。可靠做法：用 WMI 脱离进程树启动，脚本见 `.deepworks/tmp/run-server.cmd`：
  ```powershell
  ([wmiclass]'Win32_Process').Create('cmd.exe /c "D:\个人主页\.deepworks\tmp\run-server.cmd"')
  ```
  排查残留进程时按进程名过滤（`-Filter "Name = 'python.exe'"`），**不要**用 `CommandLine -match 'server\.py'`，否则会匹配到当前 shell 自身并把命令打断。
- **Python**：3.14，实测解释器 `C:\Users\LENOVO\AppData\Local\Programs\Python\Python314\python.exe`（`py` 启动器亦可）。**Node.js 不可用**。
- **PowerShell 脚本必须存为 UTF-8 with BOM**：本机是 Windows PowerShell 5.1，读取无 BOM 的 `.ps1` 时按 ANSI 解码，中文注释/字符串会把引号吃掉，表现为一堆莫名其妙的语法错误。新建/改写 `tools/*.ps1` 后，用这条命令确认（`has-BOM=True` 且 `syntax-OK`）：`$b=[IO.File]::ReadAllBytes($p); ($b[0] -eq 0xEF -and $b[1] -eq 0xBB -and $b[2] -eq 0xBF)`，再跑 `[System.Management.Automation.Language.Parser]::ParseFile($p,[ref]$null,[ref]$err)`。
- **Web 校验手段（没有 Node.js 时）**：把 `scripts/main.js` 内联进一个临时 HTML，用 Edge headless（`msedge.exe --headless=new --virtual-time-budget=... --dump-dom`）打开：`window.onerror` 可捕获语法错误，`--virtual-time-budget` 会等网络请求结束再 dump DOM，因此能真实跑完「探测状态 + 发消息 + 收回复」的完整链路。仪表盘脚本见 `.deepworks/tmp/avatar-e2e.html`（把结果写进 `document.title`）。
