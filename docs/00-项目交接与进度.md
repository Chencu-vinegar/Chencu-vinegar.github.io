一个**静态个人主页**，用于展示个人品牌、经历与联系方式，并含两个动态模块：「我的数字分身」（DeepSeek）与「意见反馈」（Supabase）。

## 5. 源文件关键信息（新对话注意）

- **入口**：`index.html`（单页，所有区块集中在此文件）。
- **样式**：`styles/main.css` —— 主题用 CSS 变量（`:root` 浅色，`[data-theme="dark"]` 深色）；表单通用类 `.field` 同时服务联系表单与反馈表单。版式为**高对比色块风格**：`--radius: 0`（仅胶囊/头像为圆）、`--color-block` 为首屏大色块底色、`--color-line` 为硬横线色、`--fs-hero`/`--fs-h2` 用 `clamp()` 自适应。规范细节见 `docs/03-设计规范.md`。
- **首屏结构**：`.hero-grid` 左右分栏 —— 左 `.hero-block`（饱和蓝大色块：eyebrow / 超大姓名 / 定位句 / `.chip` 胶囊标签 / CTA / `.hero-keywords` 低对比大字），右 `.hero-side`（头像 + 「技能关键词」`.skill-cloud` + `.side-facts` 事实列表）；下方 `.scroll-cue` 为 CSS 绘制的 V 形下滚箭头。桌面 1.5:1，≤940px 上下堆叠。
- **区块标题组件**：`.section-head`（`.section-title` + `.section-index` 两位序号 + 2px 实色下划线），序号 01–05 与五个内容区块一一对应。
- **交互**：`scripts/main.js` —— 纯原生 JS（**ES5 语法**，不用 `let`/`const`/箭头函数/模板字符串），无依赖；数字分身调用后端 `/api/chat`（失败回退本地关键词回复），意见反馈由 `submitFeedback()` 判断走直连还是后端。两个表单（`.feedback-form` 与 `.contact-form`）共用同一提交流程。
- **前端公开配置**：`scripts/config.js` 定义 `window.SITE_CONFIG`（`supabaseUrl` / `supabaseKey` / `supabaseTable`），在 `index.html` 中**先于 `main.js`** 加载。填了地址与密钥 → 浏览器直连 Supabase；留空 → 回退同源 `/api/feedback`。用 publishable 公钥是 Supabase 的既定用法，**切勿**把 `service_role` 密钥写进此文件。
- **后端**：`server.py`（Python 零依赖，仅标准库）——静态托管 + `/api/chat` 转发 DeepSeek + `/api/feedback` 写入 Supabase + `/api/health` 返回功能启用状态；所有密钥从 `.env` 读取，前端不暴露。
- **数据库**：`sql/feedback.sql` 建 `public.feedback` 表（`id/nickname/contact/category/message/page_url/user_agent/created_at`），开启 RLS 且只放行匿名 `insert`；服务端用 **anon key** 写入，读取需登录 Supabase 控制台。
- **区块顺序**：Hero → 关于我 → 经历 → **数字分身** → 联系我 → **意见反馈** → 页脚（作品区块暂未展示，已移除）。
- **HTML 锚点**：`#about` `#experience` `#avatar` `#contact` `#feedback`。
- **内容状态**：已替换为真实信息（姓名 陈渠梁、院校专业、邮箱、微信）；头像已接入真实图片 `assets/images/avatar.jpg`（替换该文件即可更换，首屏与数字分身共用），作品与更多经历待补。
- **微信号交互**：微信卡片已从 `<a href="weixin://">` 改为按钮（`#wechatCopy` + `data-wechat`），点击复制微信号并在卡片内提示「已复制」（优先 `navigator.clipboard`，`http://` 或旧浏览器回退 `execCommand("copy")`）。提示文案初始值由 JS 从元素当前文本读入并原样恢复（`wechatDefaultHint`），所以 HTML 里可以写完整备注而不被覆盖。
- **联系方式与隐私**：「联系我」为三张卡片 —— 邮箱（`mailto:`）、微信（可复制，提示标注**「非本人手机号」**）、手机号（**静态卡片，值为「详谈时提供」**，无点击/悬停交互，样式类 `.contact-item-static`）。目的是避免手机号被爬虫直接抓取。桌面 `grid-template-columns: repeat(3, 1fr)`，窄屏单列。

- **本地服务启动（Windows 注意）**：`Start-Process py server.py` 在本环境会留下多级僵尸进程（`py.exe` → `python3.exe` → `python.exe` 抢同一端口，`SO_REUSEADDR` 使旧进程继续截获请求），且子进程会随调用方 shell 结束被回收。可靠做法：用 WMI 脱离进程树启动，脚本见 `.deepworks/tmp/run-server.cmd`：
  ```powershell
  ([wmiclass]'Win32_Process').Create('cmd.exe /c "D:\个人主页\.deepworks\tmp\run-server.cmd"')
  ```
  排查残留进程时按进程名过滤（`-Filter "Name = 'python.exe'"`），**不要**用 `CommandLine -match 'server\.py'`，否则会匹配到当前 shell 自身并把命令打断。
