# 02 页面结构与信息架构（IA）

> 描述个人主页的**页面组成、导航结构、各模块的内容与交互**。本文件描述**已落地**的结构（与 `index.html` 一致），改版后请同步更新。

## 1. 页面形态方案

| 方案 | 说明 | 适合场景 |
| --- | --- | --- |
| A. 单页滑动（推荐） | 一个长页，通过导航锚点滚动到各区块 | 内容聚焦、访客体验顺畅、首屏强 |
| B. 多页面（Home / About / Works / Contact） | 分页路由，每页独立 | 内容量大、希望分区清晰 |
| C. 混合 | 单页为主 + 独立 Works 页面 | 作品多、需要单独作品集页 |

**最终形态（已确认：方案 A —— 单页滑动）：** ✅ 单页滑动

## 3. 各模块详细说明

### ① 顶部导航栏
- 内容：`陈` 字标识 + 姓名、锚点导航（关于 / 经历 / 分身 / 联系 / 反馈）、主题切换按钮、汉堡菜单按钮。
- 交互：点击导航项平滑滚动到对应区块；窄屏（≤800px）折叠为汉堡菜单，点击导航项后自动收起。
- 吸顶 + 2px 实线下边框；高度 `68px`，锚点跳转已用 `scroll-padding-top` 避让。

### ② Hero 首屏
- 版式：**左右分栏**（桌面 1.5 : 1），左侧为大色块、右侧为速览卡；≤940px 改为上下堆叠。
- 左侧大色块：
  - eyebrow：`个人主页 / 2026`（大写、宽字距、青色）
  - 主标题：`你好，我是` + **陈渠梁**（换行、超大字号、900 字重）
  - 定位句：天津大学香港理工大学深圳未来技术学院 · 2026 级学生 · 主修计算机科学与技术
  - 胶囊标签：计算机科学与技术 / 创新实践 / 技术探索 / 人工智能
  - CTA：`了解我`（白底反色，→ `#about`）、`联系我`（白色描边，→ `#contact`）
  - 装饰：`Code · Build · Explore`（低对比大字，`aria-hidden`）
- 右侧速览卡：
  - 头像（缺失时回退「陈」字）
  - 「技能关键词」标签云：计算机科学与技术 / 人工智能 / 创新实践 / 技术探索 / 编程基础 / 团队协作
  - 事实列表：院校 `TJU × HKPU` / 年级 `2026 级` / 专业 `计算机科学与技术`
- 底部：V 形下滚箭头（→ `#about`），CSS 绘制并循环浮动。

### 01 关于我
- 导语 Lede（大字号加粗，独立成行）
- 两段个人简介（正文 + 次要文字色）
- 右侧事实列表（3 条：年级 / 院校 / 专业）—— 不虚构量化数据
- 「兴趣方向」标签组（4 个胶囊标签）

### 02 经历
- 结构：`时间` / `组织·角色` / `一句话描述`；桌面为「左年份 + 右内容」两栏，≤800px 单栏堆叠。
- 当前仅 1 条（2026 — 至今 · 本科生），后续按 `04-内容清单.md` 补充。

### 03 我的数字分身
- 定位：基于本人公开信息构建的 AI 分身，用于自我介绍、答疑、闲聊。
- 界面：左侧形象面板（头像 + 名称 + 基于公开信息构建 + 在线状态徽标），右侧对话区（消息气泡、3 个快捷提问、输入框 + 发送按钮、Demo 提示）。
- 交互：真实调用后端 `/api/chat`（DeepSeek）；请求失败或无密钥时回退本地关键词回复，并通过 `/api/health` 的 `aiEnabled` 显示「AI 在线」或「演示模式」。
- **线上（GitHub Pages）无后端，因此始终处于「演示模式」**；本地跑 `py server.py` 才是「AI 在线」。
- 外壳为 2px 描边整体容器，面板与对话区之间用 2px 分隔线。

### 04 联系我
- 三张卡片（桌面三等分，窄屏单列）：
  - **邮箱**（`mailto:` 链接）
  - **微信**（`#wechatCopy` 按钮，点击复制，2 秒内提示「已复制」；提示文案标注**「非本人手机号」**）
  - **手机号**（静态卡片，值为**「详谈时提供」**，不做悬停与点击交互 —— 避免被爬虫直接抓取号码）
- 留言表单：称呼 / 邮箱 / 留言 → 提交到反馈接口，`category` 固定为「留言」

### 05 意见反馈
- 字段：称呼（选填）/ 联系方式（选填）/ 反馈类型（建议·问题·合作·其他）/ 内容（必填，≤2000 字，带实时字数）
- 防刷：隐藏蜜罐字段（命中则前端假装成功、不发送任何数据）、前后端双重长度校验
- 存储（双路径，自动选择）：静态托管时**浏览器直连 Supabase REST**；本地有后端时走 `server.py` 代理。两条路都写入 `public.feedback` 表（RLS 仅放行匿名插入）
- 状态提示：`提交中（蓝）/ 成功（绿）/ 失败（红）`

### ⑥ 页脚
- 超大低对比姓名（装饰，`aria-hidden`）、版权、返回顶部
