# 02 页面结构与信息架构（IA）

> 描述个人主页的**页面组成、导航结构、各模块的内容与交互**。结构建议采用「单页锚点 + 可选分页」两种形态，具体以确认为准。

## 1. 页面形态方案

| 方案 | 说明 | 适合场景 |
| --- | --- | --- |
| A. 单页滑动（推荐） | 一个长页，通过导航锚点滚动到各区块 | 内容聚焦、访客体验顺畅、首屏强 |
| B. 多页面（Home / About / Works / Contact） | 分页路由，每页独立 | 内容量大、希望分区清晰 |
| C. 混合 | 单页为主 + 独立 Works 页面 | 作品多、需要单独作品集页 |

**建议默认：方案 A（单页）。最终形态（已确认：方案 A —— 单页滑动）：** ✅ 单页滑动

## 2. 信息架构（方案 A：单页）

```
┌─────────────────────────────────────────┐
│ ① 顶部导航（Logo + 导航链接 + 主题切换）       │
├─────────────────────────────────────────┤
│ ② Hero 首屏                              │
│    头像 / 姓名 / 一句话定位 / 核心标签 / CTA │
├─────────────────────────────────────────┤
│ ③ 关于我（About）                          │
│    个人简介 / 技能标签 / 亮点数据              │
├─────────────────────────────────────────┤
│ ④ 经历时间线（Timeline，可选）               │
│    教育 / 职业 / 项目经历                    │
├─────────────────────────────────────────┤
│ ⑤ 作品集（Works）                          │
│    卡片网格：封面 + 标题 + 简介 + 链接        │
├─────────────────────────────────────────┤
│ ⑥ 我的数字分身（AI Avatar，Demo）           │
│    虚拟形象 + 对话界面（静态演示，未接真实能力） │
├─────────────────────────────────────────┤
│ ⑦ 联系我（Contact）                        │
│    邮箱 / 社交 / 二维码 / 联系表单（可选）     │
├─────────────────────────────────────────┤
│ ⑧ 页脚（Footer）                          │
│    版权 / 备案 / 社媒 / 返回顶部              │
└─────────────────────────────────────────┘
```

## 3. 各模块详细说明

### ① 顶部导航栏
- 内容：Logo（或本人标识）、锚点导航（关于 / 经历 / 作品 / 分身 / 联系）、主题切换（可选）
- 交互：滚动到对应区块；窄屏折叠为汉堡菜单

### ② Hero 首屏
- 素材：个人头像（圆形/方形）、姓名、一句话定位（Slogan）、1–3 个核心标签、主按钮
- 文案示例：`你好，我是 ___` + `我是一名 ___，专注 ___`
- 主按钮（CTA）：如「查看我的作品」「联系我」

### ③ 关于我
- 内容：1–3 段个人简介、技能标签（或技能条）
- 可选亮点：一段「用数字说话」(如：X 年经验 / Y 个项目 / Z 次合作)

### ④ 经历时间线（可选）
- 结构：时间 + 组织 / 学校 + 担任角色 + 一句话描述

### ⑤ 作品集
- 卡片字段：封面图、标题、一句话简介、技术/领域标签、外部链接（演示/仓库/文档）
- 交互：点击打开链接或弹窗查看；hover 有动效；可筛选分类（可选）

### ⑥ 我的数字分身（Demo）
- 定位：基于本人公开信息构建的 AI 分身，用于自我介绍、答疑、闲聊。
- 界面组成：虚拟形象（占位）、对话窗口（消息气泡）、输入框 + 发送按钮、「待机中」状态与 Demo 提示。
- 交互（当前为演示）：输入文字后按关键词给出示例回复（含输入延迟模拟）；提示「尚未接入真实对话」。
- 后续：预留接入大模型 / API 的位置（见 05-技术方案）。

### ⑦ 联系我
- 必含：邮箱（mailto 链接）
- 可选：微信 / 微博 / 小红书 / LinkedIn / GitHub / X 等，及扫码（二维码图片）
- 可选：联系表单（公司名、留言等，需后端或第三方表单服务）

### ⑧ 页脚
- 版权信息、ICP 备案（如国内托管）、社媒图标、返回顶部

## 5. 响应式布局要点
- 桌面：导航横向，作品卡片 2–3 列
- 平板：作品卡片 2 列
- 手机：单列堆叠、汉堡菜单、可点击拨打 / 复制邮箱（可选）
