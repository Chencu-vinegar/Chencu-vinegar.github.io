## 1. 阶段划分

### Phase 1 — 准备与骨架（0.5–1 天）
- 初始化项目、目录结构、基础依赖。
- 搭建全局样式与 CSS 变量（主题、色彩、间距）。
- 搭建整体布局（Header + 容器 + Footer）。
- **验收**：打开 `index.html`（或 `py server.py` 后访问 http://localhost:8000）可看到各区块骨架。**本项目无构建步骤，不需要 npm。**

### Phase 2 — 首屏与关于（1–2 天）
- 实现 Hero（头像、姓名、Slogan、标签、CTA）。
- 实现「关于我」（简介、技能、亮点）。
- **验收**：首屏文案正确、头像显示、布局在不同宽度下不破版。

### Phase 3 — 经历与作品（2–3 天）
- 实现经历时间线（已完成，「年份 + 内容」两栏）。
- 作品卡片网格：**暂缓** —— 目前无作品内容，区块已从页面移除，对应样式也已清理；日后有素材时按需加回。
- **验收**：经历内容正确、多端布局正确。

### Phase 4 — 联系与页脚（1 天）
- 实现「联系我」（邮箱 / 社媒 / 可选二维码 / 可选表单）。
- 实现页脚（版权、备案、社媒、返回顶部）。
- **验收**：邮箱 mailto 可用、社媒链接正确、页脚信息完整。

### Phase 5 — 细节与体验（1–2 天）
- 锚点平滑滚动、主题切换（可选）、动效打磨。
- 图片懒加载、尺寸修正、无障碍优化。
- **验收**：关键交互反馈顺畅、无多余抖动、可见焦点。

### Phase 6 — 性能、SEO 与部署（1–2 天）
- 性能优化、基础 SEO 标签、可选结构化数据。
- 部署到 **GitHub Pages**（已完成，无需构建步骤）。
- **验收**：线上可访问（https://chencu-vinegar.github.io/）；**具体逐项见下方 §4 上线验收清单**。
  Lighthouse 指标（`Performance / Accessibility / SEO ≥ 90`）可作为后续优化目标，尚未实测记录。
