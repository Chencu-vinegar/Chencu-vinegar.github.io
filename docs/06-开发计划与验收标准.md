# 06 开发计划与验收标准

> 按阶段拆分开发任务，每个阶段附带**验收标准**。可根据实际节奏压缩 / 展开。

## 0. 前置条件
- [ ] 确认需求方向（`docs/01` 决策点）
- [ ] 确认页面形态（单页 / 多页 / 混合）
- [ ] 确认设计风格与强调色（`docs/03`）
- [ ] 确认技术选型（`docs/05`）
- [ ] 补齐必填内容（`docs/04`）

## 1. 阶段划分

### Phase 1 — 准备与骨架（0.5–1 天）
- 初始化项目、目录结构、基础依赖。
- 搭建全局样式与 CSS 变量（主题、色彩、间距）。
- 搭建整体布局（Header + 容器 + Footer）。
- **验收**：`npm run dev` 可在本地启动，页面能进出各区块骨架。

### Phase 2 — 首屏与关于（1–2 天）
- 实现 Hero（头像、姓名、Slogan、标签、CTA）。
- 实现「关于我」（简介、技能、亮点）。
- **验收**：首屏文案正确、头像显示、布局在不同宽度下不破版。

### Phase 3 — 经历与作品（2–3 天）
- 实现经历时间线（可选）。
- 实现作品卡片网格，接入 `data/` 数据，支持外链。
- 卡片 hover 动效、响应式列数切换。
- **验收**：3–8 个作品正常显示、链接可点、多端布局正确。

### Phase 4 — 联系与页脚（1 天）
- 实现「联系我」（邮箱 / 社媒 / 可选二维码 / 可选表单）。
- 实现页脚（版权、备案、社媒、返回顶部）。
- **验收**：邮箱 mailto 可用、社媒链接正确、页脚信息完整。

### Phase 5 — 细节与体验（1–2 天）
- 锚点平滑滚动、主题切换（可选）、动效打磨。
- 图片懒加载、尺寸修正、无障碍优化。
- **验收**：关键交互反馈顺畅、无多余抖动、可见焦点。

### Phase 6 — 性能、SEO 与部署（1–2 天）
- 性能优化、基础 SEO 标签、可选结构化数据。
- 构建、部署到选定平台、配置域名与 HTTPS。
- **验收**：线上可访问；Lighthouse 关键指标达标（`Performance ≥ 90`、`Accessibility ≥ 90`、`SEO ≥ 90`）。

## 2. 全局验收清单

- [ ] 所有区块内容完整、无占位文案残留（关键处）
- [ ] 桌面 / 平板 / 手机三端布局正常
- [ ] 深 / 浅色主题可切换且无破板（如启用）
- [ ] 图片有 `alt`、懒加载、不变形
- [ ] 所有外链可访问
- [ ] 邮箱联系方式可用
- [ ] 页面加载性能达标
- [ ] 无控制台报错
- [ ] （国内托管时）页脚含备案信息
